# CODSOFT_TASKSNO
CodSoft AI Internship tasks
## Task 1: Rule-Based Chatbot
A chatbot that replies to user input using predefined rules and regex pattern matching.

**Run:** `python Task1_Chatbot/chatbot.py`

**Features:** greetings, small talk, time/date, AI basics, jokes, fallback replies.

## Task 2: Tic-Tac-Toe AI
An unbeatable Tic-Tac-Toe AI using the Minimax algorithm with Alpha-Beta Pruning.

**Run:** `python Task2_TicTacToe_AI/tictactoe.py`

**Features:** play as X against the AI, choose who goes first, replay option.
